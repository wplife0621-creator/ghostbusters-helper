정수와 넘버스는 도감에서 찾고, 빌드는 다른 유저의 조합을 참고하며, 게시판에서는 공략과 질문을 확인하면 됩니다.

정수 검색 내 보관함 변경 이력
1. 정수 찾기

몬스터명, 효과, 추천 캐릭터, 층과 구역으로 필터링하세요. 비교하고 싶은 정수는 체크하거나 통합 검색에서 비교함에 담으면 됩니다.

정수 페이지 열기
2. 넘버스 확인

번호, 착용부위, 획득처, 효과 기준으로 확인하세요. 번호를 모르는 장비는 미확인 정보로 관리됩니다.

넘버스 페이지 열기
3. 빌드 참고

공개 빌드를 최신순과 좋아요순으로 보고, 캐릭터별 정수 세팅과 합산 스탯을 확인하세요.

빌드 페이지 열기
4. 공략과 제보

로그인 후 게시글과 제보를 작성할 수 있습니다. 틀린 정보는 정보 제보/수정에서 바로 알려주세요.
