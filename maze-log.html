미궁 일지

미궁에 들어갈 때마다 한 줄씩 기록해두는 개인 기록장입니다. 시작 일수를 정한 뒤 회차를 추가하고, 각 층에서 균열이 나왔는지, 며칠 몇 시에 나왔는지, 봉헌이나 특수 몬스터가 있었는지 바로 남겨두세요. 자주 다시 시작하는 게임 흐름에 맞춰 도전별 시트를 나눠 관리할 수 있습니다.

총 회차 0 최근 기록 - 5층 특수 젠 0
간단 사용법
  • 1. 시작 일수를 저장한 뒤 회차 추가를 눌러 기록을 만드세요.
  • 2. 표 아래의 수정 모드를 누른 뒤 원하는 칸의 입력 버튼을 눌러 균열 일·시, 봉헌, 특수 젠을 기록하세요.
  • 3. 기록은 이 브라우저에 저장됩니다. 캐시/사이트 데이터 삭제, 다른 기기 접속, 시크릿 모드에서는 기록이 사라질 수 있으니 가끔 백업하기를 눌러 보관하세요.
균열 주기 참고

대략 4회차~7회차 주기로 보고, 실제 기록과 비교하면서 다음 균열을 예측해보세요.

1층4일~12시간 2층7일~3일 3층10일~5일 4층19일~12일 5층26일~18일
현재 120일차부터 기록하고 있다면 120을 입력하세요. 다음 추가 행은 기존 기록 다음 또는 시작 일수부터 생성됩니다.

기록은 자동으로 이 브라우저에 저장됩니다.

항목 추가

표에 더 보고 싶은 층이 생기면 이름, 균열, 특수 젠 항목을 직접 추가하세요.

회차별 기록

수정 모드를 켠 뒤 필요한 칸만 입력하세요. 표 오른쪽 + 버튼이나 상단의 층 설정 추가로 원하는 층 항목을 더할 수 있습니다.

아직 기록이 없습니다. 아래 + 회차 추가를 눌러 시작하세요.

수정 모드를 켜면 빈칸의 입력 버튼과 전체 수정 버튼이 나타납니다.
