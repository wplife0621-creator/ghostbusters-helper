10일 단위로 쌓는 미궁 기록

미궁 1회 진입을 10일 단위로 보고, 각 회차별 균열 출현과 1층 봉헌 사용, 5층 특수 몬스터 젠 여부를 기록합니다. 현재 공개된 1~6층은 기본 제공하고, 표 오른쪽의 + 버튼으로 필요한 층 항목만 추가할 수 있습니다.

총 회차 0 최근 기록 - 5층 특수 젠 0
현재 120일차부터 기록하고 있다면 120을 입력하세요. 다음 추가 행은 기존 기록 다음 또는 시작 일수부터 생성됩니다.

기록은 자동으로 이 브라우저에 저장됩니다.

항목 추가

표에 더 보고 싶은 층이 생기면 이름, 균열, 특수 젠 항목을 직접 추가하세요.

회차별 기록

기록할 칸을 누르면 해당 회차와 층만 바로 입력할 수 있습니다. 오른쪽 + 버튼으로 필요한 층을 추가할 수 있습니다.
